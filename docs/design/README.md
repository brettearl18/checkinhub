# UX / UI redesign branch

This branch (`ux-redesign`) is for redesigning CheckinHUB UX/UI **without changing production**.

- **Production** deploys from `main` → https://checkin.vanahealth.com.au
- **This branch** is safe for experiments; Vercel may create a **Preview** URL when pushed — that is not the live site.
- Merge to `main` only when the redesign is ready to go live.
